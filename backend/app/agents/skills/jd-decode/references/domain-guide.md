# 分类与证据

必要条件只代表 JD 明示的申请要求，不代表已知雇主所有筛选逻辑。每条记录：要求、类别、原句、需要核对的问题。

| 材料 | 处理 |
| --- | --- |
| 熟悉 Python，Docker 优先 | Python 是要求；Docker 是加分项 |
| 参与需求分析与原型验证 | 职责；寻找访谈、需求取舍、原型与验证产出 |
| 2027 届 / 具体毕业日期窗口 | 申请资格；原样保留，拿候选人日期核对 |
| 无学历 / 薪资 / 工时信息 | 未说明；不猜公司、资历或工时 |

依据：University of Michigan HR [Writing a Job Description](https://hr.umich.edu/working-u-m/management-administration/compensation-classification/compensation-classification-tools-procedures/how-write-job-descriptions) 将职责与必要/优先资格分开。Greenhouse [Resume parsing](https://support.greenhouse.io/hc/en-us/articles/200989175-Unsuccessful-resume-parse) 描述解析与失败处理，不能据此推导招聘通过率。具体校招资格以当期公司官方招聘信息为准。

这些资料支持分类和核对方法，不证明本产品优于其他 AI，也不提供招聘方隐藏决策。
