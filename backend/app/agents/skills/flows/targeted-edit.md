# 局部修改

1. 判断是不是更正事实：数字、日期、条数、角色等说错了 → 先 record_facts。只有返回 correction_applied 才表示正文已同步改好，此时不要再改写；没有 correction_applied 时再用 edit_resume 改正文。
2. 普通修改 → edit_resume，instruction 用用户原话 + 明确目标（经历名 + 哪一条），例如「电商公司实习：订单查询接口那条放第一位并写得更突出，其他不变」。用户用「那个项目」「上面那条」指代时，在 instruction 里换成具体名称。
3. 只改用户点到的地方，其他条目、顺序、技术栈保持不变。
4. 看结果：changed=false 或 insufficient → 如实说没改成和原因（例如没定位到哪一条），请用户点名；不要连续重试超过一次，不要说「已改好」。
5. 回复只讲 change_summary 里真实发生的改动；不要讲工具内部过程（「前两次定位失败」之类）。
