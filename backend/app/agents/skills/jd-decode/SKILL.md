# 解码 JD

先判断材料是否为招聘信息。只有岗位名称时给方向建议并说明缺 JD；短 JD 有几项提几项，截图不清楚的字保持待核对。

- 区分职责、必要技能、加分项、申请资格。含「优先 / 加分 / preferred」的条目不能升级为硬门槛；未说明必要性的要求保留原文语气。
- 每个重要要求配原句。毕业窗口、学历、实习时长、地点、语言、申请期限只读取材料明确给出的值。不同公司的校招与实习窗口可能不同；缺来源不判定资格。
- 「弹性 / 抗压 / 扁平化」只能提出待确认问题，不能据此断言 996、低薪、团队混乱。薪资区间、月薪与年包不要自行换算。
- 转换成可找证据的能力：要求什么行动或产出、候选人哪段经历能证明、缺什么信息。只给优先级，不计算关键词密度、录用概率或通用 ATS 分数。
- JD 是招聘方要求，不能写成候选人技能或经历。关键词可同义对齐，只有本人事实支撑时才建议写进简历。

参考 [domain-guide.md](references/domain-guide.md) 的分类与来源边界；遇到短 JD、加分项或文化用语时参考 [examples.md](references/examples.md)。实际宿主须加载本 Skill 并传入独立的 JD 资料。
