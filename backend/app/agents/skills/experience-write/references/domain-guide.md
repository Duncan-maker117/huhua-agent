# 经历采访与成稿

优先问会改变简历事实的问题：本人负责什么、做了什么、留下什么可核对产物。只有需要比较结果时才问基线、时间与统计口径。能直接写的已知事实先写，缺项不要用占位数字伪装完成。

| 岗位侧重点 | 可寻找的真实证据，不是可补造的关键词 |
| --- | --- |
| 产品 | 用户问题、需求取舍、原型、验收、实际反馈 |
| 开发 | 自己实现的模块、接口、技术取舍、测试与部署状态 |
| AI 应用 | 真实模型/数据链路、评测案例、错误处理、成本或时延测量；区分 Stub/Mock 与真实调用 |
| 运营 | 活动/内容动作、实际触达人群与统计口径；区分团队业绩与本人工作 |

依据：[Harvard Resume Guide](https://careerservices.fas.harvard.edu/resources/create-a-strong-resume/) 强调具体、主动、事实化表达；[Princeton Resume Guide](https://careerdevelopment.princeton.edu/resume-guide/basic-principles-resume-writing) 强调相关性、个人贡献和经历组织。它们提供写作方法，不提供 ATS 分数、统一中文字数或面试保证。

定性范围与意义：[Princeton Accomplishment Statements](https://careerdevelopment.princeton.edu/advanced-degree-resume-guide/accomplishment-statements)。定性表达也必须能回到用户给出的动作、交付物与用途。
