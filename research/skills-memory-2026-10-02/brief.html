02 / 三个 Skill 的职责

通用格式规定指令包，网站仍需要实现功能路由、加载与结果校验。当前三个入口已映射到项目内指令包。宿主集成依据

系统 Prompt 设计与效果边界 · JD/检查补充资料 · 经历/Prompt 补充资料

01解码 JD

输入
完整 JD；截图先转写为可核对文字。岗位方向可作为不足材料时的补充。
输出
必要条件、加分项、职责及 JD 原句；需要证明的能力；待确认问题。趣味解读单独标记为推测。
方法
识别明确要求与优先项，按招聘原文分类；从职责推导需要展示的证据，并保留推导标签。
信息不足
短 JD 不凑固定数量；看不清的截图或未写明的要求保留未知。
质量门槛
要求可定位到原文，必要条件和加分项不混淆，推测不进入事实字段。
当前接入点
已接 decoder_chain 的两条分支，加载 JD Skill；Python 验证字段结构和原句存在，不能证明所有语义判断正确。
合格示例

原文“Docker 优先”：列入加分项，附原句。

失败示例

把“优先”当硬门槛，或根据“抗压”直接断言薪资低、必然加班。

设计依据 S01 S02 S03 R01 R05 R06 · 接入点来自本项目代码审计

02包装经历

输入
用户原话、本人角色、行动、交付物、可证明结果；目标岗位或能力方向。
输出
推荐 bullet、对应事实原句、未解决信息及一个最影响表达的追问。
方法
先整理事实，再围绕目标能力改写动作和产出；没有业务结果时保留定性表达。原始事实与改写稿分别保存。
信息不足
缺结果时说明完成了什么；需要数字时追问实际口径，不估算补齐。
质量门槛
职责、数字、技术和效果均有输入依据；采用的改写实际进入同一份预览与导出数据。
当前接入点
已接 COLLECTING_WRAP，共同系统规则也用于最终编辑器；改写保持建议，导出仍按现有事实摘取校验，采用改写的契约待设计。
合格示例

已说“参与后端开发，写了10条接口测试”：保留参与范围与10条测试。

失败示例

改成“主导系统上线，效率提升50%”，把候选表达当已确认的个人事实。

03检查简历

输入
当前最终 ResumeData、目标 JD；可选原话、证明材料及实际导出解析结果。
输出
原句或字段位置、问题与依据、修改动作；区分原文明示不符、材料未展示、部分可迁移与来源未说明。
方法
规则检查姓名、联系方式、空项、日期和结构；语义检查岗位要求对应的经历证据，区别“列出技能”与“用经历证明能力”。
信息不足
无 JD 时做通用检查；缺本人事实先追问，不生成含新动作的正文或填空范例。
质量门槛
问题可定位、建议可执行、没有新增事实；声明检查范围。
当前接入点
已加独立检查任务，读取本轮材料与完整当前数据作内容建议；保留确定性检查，不回写个人事实。
合格示例

指出“负责开发系统”缺具体个人动作，追问实际负责哪一部分。

失败示例

凭关键词给出“ATS 92分、保证面试”；未检查导出就声称版式合格。

03 / 三类可选记忆

后续选型前，先决定你希望用户第二次打开产品时少做哪些重复工作。

真实经历库

新对话和新岗位可复用已保存的项目、实习、职责、日期、技术和实际结果。

候选记录：owner_id、experience_id、用户原话/来源 ID、结构化事实、确认状态、修订时间、被替代记录 ID。

边界：模型建议与岗位 JD 不能直接变成个人经历；更正要覆盖当前有效事实并保留可解释来源。

表达与版式偏好

记住简洁程度、中文/英文、模板和表达习惯，减少重复说明。

候选记录：owner_id、偏好键和值、用户来源、作用范围、更新时间。

边界：改风格不改职责与数字；本次任务临时偏好不要自动变成永久偏好。

岗位与简历版本

同一事实库形成 AI 产品版、开发版等不同岗位简历；保存核对与编辑结果。

候选记录：owner_id、job_id、JD 来源、version_id、采用的事实 ID、改写内容、模板、版本状态。

边界：岗位强调点只属于对应版本；切换岗位不改全局事实，也不能只靠聊天 session_id 推断账户归属。

LangGraph Store

贴合现有框架

按 namespace 存取跨线程资料，与同会话 checkpointer 分工。可与自建事实表结合，不是互斥产品。

依赖
持久 Store（如 PostgresStore）+ 资料归属 + 应用写入/检索规则
接入成本判断
较低至中等；无需换 Agent 主流程
局限与版本
Store 不自动决定何时记忆、事实真伪、授权和更正策略。语义索引是否启用要单独配置；当前安装版本兼容性未试验。
数据路径
使用自有数据库可自管存储；语义检索额外涉及配置的 embedding 服务；模型只接收应用选取的资料。
证据范围
官方区分 thread checkpoint 与跨线程 Store，提供持久化及 namespace 接口。
