# 检查依据与范围

| 证据层级 | 可以说什么 |
| --- | --- |
| 技能栏声明 Python | 声明会使用；尚缺具体项目证据 |
| 项目注明自己用 Python 编写接口 | 有动作/对象证据；不自动代表熟练或生产经验 |
| 项目未提 Python | 材料未展示；可问是否有实际使用经历 |
| 明确不会 Python | 已知缺口；不能建议直接加关键词 |

资格要求原样核对来源、毕业窗口与项目类别，未提供日期时保持未知。日期以材料范围检查，不推测毕业或任职年限。

Greenhouse 官方解析资料列举复杂版式可能导致解析问题，但不证明任何版式必然失败；其自动拒绝规则可由雇主设置的申请问题触发，不是一个统一关键词分数。格式建议是风险提示，须通过实际导出文本/页面检查才能验证。

来源：[Greenhouse Resume parsing](https://support.greenhouse.io/hc/en-us/articles/200989175-Unsuccessful-resume-parse)、[Harvard Resume Guide](https://careerservices.fas.harvard.edu/resources/create-a-strong-resume/)。专业问题的完整来源映射见项目研究目录的 jd-review-sources.md 与 writing-prompt-sources.md。
