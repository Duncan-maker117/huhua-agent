# 算法工程师（机器学习 / NLP / CV / 大模型 / 推荐，校招 / 实习）

## 筛选者看什么（按权重）
1. **问题建模与方法**：任务是什么（分类/检索/生成/排序），用了什么模型/方法，为什么。
2. **实验与指标**：数据集、基线、指标（Acc/F1/AUC/BLEU/Recall@K/胜率）、提升幅度、消融。**没有指标的算法经历几乎没有说服力，必须追问。**
3. **本人贡献**：在论文/项目中具体负责哪部分（数据处理、模型改进、实验、部署）。
4. **工程落地**：训练/推理框架（PyTorch、DeepSpeed、vLLM）、部署、加速、资源规模（GPU 数、数据量）。
5. **学术产出**：论文（会议/期刊、作者排序、状态：在投/接收）、竞赛排名（Kaggle/天池）。
6. 大模型方向：SFT/RLHF/DPO、RAG、Agent、评测、数据构造。

## 成果口径
- 指标：相对基线提升 X 点（绝对值还是相对值要说清）、榜单排名
- 规模：数据量、参数量、GPU 卡数、训练时长
- 效率：推理延迟、吞吐、显存、成本
- 产出：论文状态与作者位次、专利、开源 Star、竞赛名次/参赛队伍数

## 表达
- 推荐动词：提出、设计、构建、训练、微调、优化、评测、复现、部署
- 句式：**[任务] + [方法/改进点] + [在什么数据上相对什么基线提升多少]**
- 避免："熟悉深度学习""了解 Transformer"。

## 改写示例（方法演示）
- 原话：「实验室做的文本分类，我主要试了几个预训练模型，最后用 roberta 加了个数据增强，比原来好了三个点左右」
- 改写：「对比多个预训练模型用于文本分类，基于 RoBERTa 引入数据增强，效果较原方案提升约 3 个点」
- 不能写：「F1」（用户没说是哪个指标）、「负责模型选型」（"我主要试了"支持对比实验，不一定支持选型决策权）。
- 追问："三个点是准确率还是 F1？在什么数据集上？最后用哪个模型是你定的吗？"

## 高价值追问
- "用的什么数据集、多大？基线是什么？指标提升多少？"
- "你本人负责的是哪部分？"
- "论文现在什么状态？你是第几作者？"
- "有没有部署或在线上用？"

## 常见坑
- 把"跑通开源代码"写成"提出新方法"。
- 只写模型名不写指标；指标不写基线。
- 论文在投写成已发表。
