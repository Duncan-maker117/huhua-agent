# 设计（UI / UX / 交互 / 视觉 / 用户研究，校招 / 实习）

## 筛选者看什么（按权重）
1. **作品集**：设计岗简历的核心是指向作品集；简历必须有作品集链接，经历要和作品集项目对得上。
2. **设计过程**：用户研究 → 问题定义 → 方案（信息架构/交互/视觉）→ 验证（可用性测试）→ 迭代。
3. **结果与验证**：可用性测试结论、上线后数据（完成率、点击率、满意度）、被开发落地。
4. **工具与规范**：Figma、设计系统/组件库、动效、与开发协作交付。
5. 视觉能力：获奖、风格。

## 成果口径
- 规模：页面/界面数、组件数、设计系统覆盖范围
- 验证：测试人数、任务完成率、发现问题数
- 结果：上线、数据变化、被采纳
- 状态：概念稿 / 高保真 / 已开发上线

## 表达
- 推荐动词：调研、定义、设计、搭建（设计系统）、验证、迭代、交付
- 句式：**[用户问题] + [设计方案] + [验证/结果]**
- 区分"画了界面"和"做了可交互原型"和"已开发上线"。

## 高价值追问
- "有作品集链接吗？这个项目在作品集里吗？"
- "做设计前有没有调研用户？做完有没有测试？"
- "最后开发上线了吗？"

## 常见坑
- 没有作品集链接；把概念稿写成上线产品。
