## 使用与范围

- 在输入框发送单个完整 HTTP(S) 招聘链接且不带附件，会读取网页并运行原有 JD 解码；也可以点“读招聘链接”。GitHub 主页/仓库链接进入公开资料核对，不替换 JD。
- 明确说“查看/核对/查一下”并附一个公开链接，服务端自动触发一次公开资料读取。例如“你看查一下我的仓库 github.com/example”。不带协议的 GitHub 链接也支持；多链接、附件、否定联网或普通经历叙述不会触发。
- GitHub 主页经官方公开 API 读取基本资料和最多 5 个最近更新的公开仓库（最多 2 次请求），具体仓库读取元数据与 Stars/Forks（1 次请求）。不读取私有内容，不保证完整项目列表，不声称已审阅代码。实现依据：[GitHub 仓库 REST API](https://docs.github.com/en/rest/repos/repos)。
- “查公司岗位”使用独立的公司名、岗位名字段，最多各 80 字，至少填一个。搜索服务仅收到这些词，不收到简历、对话或账号资料。模型随后对照本次会话已有经历给建议。
- 来源卡片显示原链接、正文摘要、获取时间及网页明确标注的发布日期。搜索摘要不等于全文核实，不保证职位仍有效。
- 搜索分析是只读操作，不更换目标 JD、不自动改写简历、不把网页中的第一人称或要求归档为本人事实。
- 无法读取登录页、动态页面、验证页或不可达页面时，保留输入，提示粘贴 JD 原文或上传截图。没有绕过登录、验证码、网站访问限制的机制。

这是用户触发的一次工具调用接入现有 LangGraph 流程。没有引入无上限的自主浏览循环，也没有接管用户账号访问招聘网站。

## 接口与执行路径

`GET /api/chat/tools` 公开返回布尔能力：`read_url`、`read_public_url` 与 `search`，不返回配置或密钥。

`POST /api/chat/stream` 保留原有字段，可增加以下一个动作：

```json
{"web_tool":{"action":"read_url","url":"https://招聘网站/职位"}}
```

```json
{"web_tool":{"action":"search","company":"公开公司名称","role":"后端实习"}}
```

服务端获取资料，客户端不能注入工具结果。读链接强制进入 `decode_jd`，搜索强制进入 `research_job`；不受客户端的改写任务选择影响。新增 SSE `tool_status` 与 `sources`，随后沿用正文、`meta`、`[DONE]`。工具失败不调用模型、不自动重试外部服务。

公开资料读取使用 `{"web_tool":{"action":"read_public_url","url":"https://github.com/example/tool"}}`；明确自然语言请求可省略 `web_tool`。该动作复用只读 `research_job` 路由并使用独立公开参考提示，来源标记 `public_page`，记录获取时间、`read_scope` 与 `request_count`；不归档为本人事实，不改稿。只有自动任务且当前消息不含附件时才推断链接意图，已选择的改写/核对任务保持原意。

## 来源与隐私

`web_research.py` 输出标题、原链接、正文和时间；图状态 `web_sources` 使用现有加密 checkpoint 保存。网页 HumanMessage 标 `jd`，研究请求标 `reference`。游客登录后导入历史仍沿用该来源类型，不能变为本人事实。

外部文本只作为不可信材料参与分析，不能覆盖系统规则。研究节点只读当前已保护的简历、经历和 JD，不额外载入长期档案；联系方式经过现有脱敏边界、头像移除。个人经历不发送给搜索服务，但当前经历和公开来源会发送给原有生成模型用于对照分析。

HTTP(S) 读取逐跳解析公共 IP，拒绝私有/保留地址和带凭证的 URL，实际连接固定已验证 IP，保留原域名的 Host、TLS SNI 与证书验证。最多 3 次跳转，原始和解压后响应均不超过 1 MiB；不读取环境代理、不携带浏览器 Cookie，不执行网页脚本。日志只记录类型/状态，不记录 URL、查询正文或凭证。

## 搜索配置

读取公开招聘链接无需新 key。全网搜索通过 [Tavily Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search) 的固定 HTTPS 端点调用，`basic` 深度，每次最多 4 条，关闭生成答案、原始全文与图片。没有引入新 Python 依赖。

凭证只写在本机 `backend/.env` 或服务器 `/opt/huhua/deploy/app.env`：

```dotenv
TAVILY_API_KEY=
```

留空时搜索关闭，界面显示“未开通”；链接读取和其他功能继续工作。部署不自动注册服务或开通付费。配好 key 后重建应用容器，再检查能力接口与一次真实搜索；布尔值变为 true 只证明配置存在，不代表服务商验证通过。

服务器更新沿用宿主机 Caddy：

```sh
cd /opt/huhua
sudo docker compose --env-file deploy/compose.env -f compose.yaml -f deploy/compose.host-caddy.yaml up -d --no-deps --force-recreate --wait app
```

不要使用不带 `deploy/compose.host-caddy.yaml` 的启动命令。运行配置不进入源码包、Git、日志或报告。
