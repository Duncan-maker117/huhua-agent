MCP 接入

把胡话简历，
接进你的 AI 助手。

Claude Code / Cursor / Codex 读取你的档案，按岗位写法起草，
再套进和网页同一套固定模板：真实测页数、看预览、导出 PDF / Word。

  1. 01

    生成个人令牌

    正在确认登录状态…

    令牌和你的账号绑定，先用邮箱验证码登录。

    登录服务暂时不可用，请稍后再试。

    允许助手做什么

    默认不给联系方式：助手看不到你的电话和邮箱，导出时由服务端填入。

    令牌只显示这一次

    离开或刷新页面后无法再次查看，请现在复制保存。

  2. 02

    复制接入配置

    在终端运行
    claude mcp add --transport http huhua https://resume.yikuaibanz.cn/mcp --header "Authorization: Bearer <你的令牌>"

    生成令牌后，这里会自动填入真实令牌。

  3. 03

    在助手里直接说任务

    按 JD 改简历

    用胡话简历里我的档案，按这份 JD 改一版简历，并导出 PDF：<粘贴 JD>

    先取岗位写法，只用已确认档案事实、逐条带出处；按固定模板测页数、看预览，再导出。

    Claude Code：/mcp__huhua__tailor_resume_for_jd

    调到一页

    把我在胡话简历里最新的那份简历调到正好一页，给我看预览

    逐条测出每句占几行、缩几个字能省一行，只压缩措辞，不增删事实。

    Claude Code：/mcp__huhua__fit_to_one_page

    把项目记进档案

    读一下这个仓库，把我负责的部分整理成建议，提交到胡话简历档案

    只提交为待确认建议，需你在网页「我的档案 → 信息确认」确认后才入档。

    Claude Code：/mcp__huhua__log_project_to_profile

    检查简历依据

    检查这份简历里哪些说法在我的胡话简历档案里找不到依据

    逐条对照档案事实，标出没有出处的句子。
