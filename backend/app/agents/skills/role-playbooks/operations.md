# 运营（内容 / 用户 / 活动 / 增长 / 新媒体，校招 / 实习）

## 筛选者看什么（按权重）
1. **数据结果**：运营岗几乎完全看结果——粉丝增长、阅读/播放、互动率、转化、活动参与人数、GMV、留存。**必须带口径与时间范围**，并区分本人负责的账号/活动与团队整体。
2. **具体动作与方法**：选题、内容策划、社群运营、活动策划执行、投放、用户分层、SOP。
3. **平台理解**：小红书/抖音/公众号/B 站/社群的算法与玩法，爆款拆解。
4. **复盘能力**：做完知道为什么好/为什么不好，下一次改了什么。
5. 工具：剪辑、设计、数据后台、Excel。

## 学生能拿出的证据
个人自媒体账号、社团公众号、校园活动、实习账号运营、电商店铺、社群。个人账号的真实数据很有价值。

## 成果口径
- 内容：篇数/条数、阅读/播放、点赞收藏、爆款数（定义爆款标准）、涨粉
- 活动：参与人数、报名转化、成本、满意度
- 用户：社群人数、活跃率、留存、复购
- 时间：X 周/月内（没有时间范围的数字意义有限）

## 表达
- 推荐动词：策划、运营、搭建、执行、拆解、复盘、优化、增长
- 句式：**[负责什么账号/活动] + [关键方法] + [数据结果（含时间范围）]**
- 格式：「独立运营[平台][主题]账号，[时间范围]内产出[N]篇内容，涨粉[N]，单篇最高[N]赞」——方括号全部必须来自用户事实，缺哪项就追问哪项或删掉该片段
- 避免："具有较强的运营思维""热爱互联网"。

## 改写示例（方法演示）
- 原话：「大学一直在弄社团的公众号，每周发一两篇，后来阅读量涨了不少」
- 改写：「负责社团公众号内容运营，保持每周 1–2 篇更新」
- 追问："接手时和现在的平均阅读大概多少？有没有哪篇特别火，为什么火？"——拿到数字前不写"阅读量显著提升"。

## 高价值追问
- "具体数据是多少？时间范围多长？"
- "这些是你一个人做的，还是团队？你负责哪块？"
- "最成功的一次是什么？你觉得为什么成功？"

## 常见坑
- "涨了很多"无数字；团队数据写成个人数据。
- 只写"负责运营"无动作无结果。
