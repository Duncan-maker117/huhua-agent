# 胡话简历官网主页设计（v1）

> 目标：`resume.yikuaibanz.cn` 首屏是产品官网，讲清楚"这是什么、为什么可信、两种用法"；聊天工作台移到 `/chat`。
> 视觉：沿用你给的 Claude 风格参考——暖纸底 + 墨色字 + 衬线大标题 + 陶土橙只做点缀，按钮一律深色。

## 1. 路由

| 路径 | 内容 | 说明 |
|---|---|---|
| `/` | **新官网主页** `web/home.html` | 带 `?session=` 的旧链接自动跳 `/chat?session=…`，旧书签不失效 |
| `/chat` | 现在的聊天工作台 `web/index.html` | 原样搬过去 |
| `/resume` | 简历编辑页 | 「回到聊天」改指 `/chat` |
| `/mcp` | MCP 接口 | 不变 |

## 2. 视觉 token（中文适配）

- 底色 `#f8f8f6`，卡片 `#ffffff`，次级面 `#efeeeb`，正文 `#121212`，次级 `#373734`，弱化 `#7b7974`，细线 `#e7e6e1`，页脚 `#000`
- 点缀色陶土橙 `#d97757`：只用于小圆点、序号、插画细节；**不做按钮**
- 标题衬线：`"Source Han Serif SC","Noto Serif SC","Songti SC","STSong",serif`，字重 400（中文宋体不加粗）
- 正文：`-apple-system,"PingFang SC","Microsoft YaHei",system-ui,sans-serif`，最重 600
- 圆角：按钮/输入 8px，卡片 16px，大卡 24px；阴影只用 `rgba(0,0,0,.04) 0 4px 20px`
- 最大宽 1200px，段间距 80–96px（移动端 56px）
- 不加载外部字体（国内访问慢），无渐变、无发光

## 4. 交互

- 「开始对话」→ `/chat`；「在 Claude Code 里使用」→ 滚到 MCP 卡；未登录点「生成令牌」→ 跳 `/chat` 并打开登录
- 已登录访问 `/`：导航右侧变「进入工作台」+「我的档案」
- MCP 命令卡的「复制」按钮复制通用命令（令牌占位 `<你的令牌>`）
- 移动端（390px）：导航折叠为 logo + 「开始」按钮；两种用法卡上下排；对照块上下排
