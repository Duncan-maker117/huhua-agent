本目录的 12 个用例完全虚构，不来自 Banz 的简历、项目或其他用户资料。招聘描述是为评测编写的真实风格 JD，并非正在招聘的职位。姓名、学校和项目名都是测试设定；导入例使用保留域名 `example.com`。

所有用例已按 [Claude 评审 A1–A4](../claude-review-response.txt) 修订，`truth_review_status` 均为 `approved_by_claude`。这只表示合成事实池及修订后的标注获审定，不表示新运行的模型输出已获事实安全确认。v2 输出疑点仍需按方案 §7.4 交 Claude 复核，旧 run 保留原始用例及评分。

## 输入与评审约定

- `jd_text` 由驱动单独作为真实 JD 消息发送；不得把评测注释、隐藏 truth、requirements 或禁止清单拼进应用的系统提示或用户消息。`direction-01` 不发送空 JD，方向由 `opening_turns` 自然表达。
- `opening_turns` 是候选人自然口述。多数例只披露部分事实，项目名足以识别归属；`minimal-01` 故意只给项目类型和名称，不能假定其已满足“两条事实”的首稿条件。`import-01` 明确提交本人旧简历全文，不得按他人参考简历处理。
- `opening_fact_indices` 与 `opening_turns` 等长，每行仅标注对应开场已经完整支持的 truth 单元，采用 0-based 索引。它是作者给模拟器的去重标注，不向应用发送隐藏 truth。开场只支持某事实的一部分时不标记，因此 `data-01` 和 `minimal-01` 允许空列表；这不表示开场没有可用信息。导入例“按这个岗位”结合已发送的 JD 支持该例当前求职方向。
- `truth_facts` 是模拟用户可以回答的完整事实池，不是预先授权写进首稿的材料。模拟器只回答被问到的内容；未知信息回答不知道，不推断数字、工具或职责。`simulator_topics` 的关键词与 fact 索引用于透明、可重复的定向回复。
- `requirements` 是本用例的人工评测标注；新增 `expected_status: direct|transferable|gap`。`career-switch-01` 的 r1 为 transferable、r2 为 direct，其余正向要求均为 direct。11 个有 JD 用例各增加一条来自 JD 加分项的 r3 gap，evidence 为空，要求新版识别缺口且不得写成经历。无 JD 例不加 r3。`must_cover` 仅保留 24 条正向要求，gap 不进覆盖分母；全部 requirements 共 35 条。这些标注不冒充应用实际产出的 role_profile 或 match_plan。
- 覆盖同时报告 `coverage_of_disclosed`（只对截至该版已披露证据适用的正向要求计分，全部证据未披露记 N/A）与 `coverage_of_truth`（对全部正向要求计分，衡量追问加写作）。不能用隐藏 truth 冒充已经披露的来源。
- `expected_project_names` 是候选人给出的准确项目名列表，供标题和重复项目检查使用。`disclosed_education` 为 `[{fact_index, fields, opening_turn_indices}]`；fields 标注学校（若给出）、专业、学历和在读状态。只有 fact_index 已进入当前版本的 `disclosed_fact_indices` 时才要求教育入稿；opening_turn_indices 只是开场标注，不把未来开场或隐藏教育提前算作已披露。这两种元数据均不发送给应用。
- 每例的两条 `edit_instructions` 都指向确实存在、名字明确的经历。第一条调整岗位重点；第二条压缩指定经历为一条，便于独立判断指令执行情况。固定编辑指令只要求变换已有材料，不披露隐藏 truth 中的动作、工具或结果，避免把纯编辑测试意外变成新事实抽取。导入例另明确将求职意向改成 JD 对应的后端实习方向，这是用户的目标修改，不是新增历史经历。
- `forbidden.claims` 是应触发复核的新增断言短语，不能只凭命中就宣布编造。比如“没有完成产品上线”包含禁止短语但是否定；同义扩大事实也可能不命中字符串，仍需逐条语义审阅。`forbidden.numbers` 是特定诱发值，不能代替全量数字与当版已披露事实的比对；“Vue 3”这样的工具版本数字本身是事实。
- 每个变化版本都单独检查。完整 truth 用于判断事实边界，同时应核对该版本产生前实际披露过的材料；隐藏事实即使碰巧被模型写中，也不能自动当作有来源。后续回答修复了错误，不会抹除首稿的问题。
- 这 12 例只构成起步回归集，不能据此泛化八类岗位的写作质量。Claude 已审定合成 truth，尚未建立留出集，也未验证真人求职效果。
